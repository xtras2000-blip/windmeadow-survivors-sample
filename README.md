# 바람 들판 서바이버즈 (플레이 샘플) — 창원 남양동 맵 추가

뱀서류 + 뷰맛집 분위기의 브라우저 플레이 샘플입니다. (three.js r187, jsDelivr CDN)

- **맵 선택**: 메뉴에서 `창원 남양동`(기본) / `바람초원` 선택 (`?map=meadow` 로 직접 지정 가능)
- 조작: 화면 아무 데나 손가락으로 끌면 조이스틱, 공격은 자동
- 📐 버튼: 낮은 풍경 시점 전환
- 5분 버티면 클리어, 4분에 보스
- 가로 화면 권장

## 창원 남양동 맵 (실제 지도 기반)

- 건물·도로·공원·하천·학교·아파트 단지: OpenStreetMap 데이터(2026-11-14 16:21 KST 수집)
- 행정경계(법정동): V-World 공간정보(2023-07-29판, KnellBalm/kr-admin-geojson 경유), 단순화됨(±50 m)
- 아파트 층수·동수 교차검증: 공공 K-apt 단지 정보
- 건물 높이는 OSM `building:levels`(층당 3 m) 기준, 정보가 없는 건물은 추정값
- 플레이 영역은 경계 외곽 사각형(약 1.1 × 1.5 km). 바깥은 흐리게 표시
- 가까운 건물은 시야 확보를 위해 낮게 보였다가 멀어지면 실제 높이로 자랍니다(연출)

## 🚶 탐험 모드 (GTA풍 첫 버전, 창원 남양동)

- 열기: 메뉴의 `탐험 모드 · 남양동` 버튼, 또는 주소에 `?mode=explore` (`explore.html`)
- 조작(폰): 왼쪽 화면 = 이동 스틱 · 오른쪽 화면 끌기 = 카메라 회전 · 두 손가락 벌리기/＋－ = 확대
- 조작(PC): WASD · 마우스 드래그 = 회전 · 휠 = 확대 · 스페이스 = 점프 · E = 상호작용
- 사람(보행로를 걸음)·자동차(우측통행 차선, 서로·플레이어 앞에서 멈춤)가 OSM 도로 데이터를 따라 다닙니다.
- 물리(직접 구현한 가벼운 물리): 중력, 점프, 계단 오르기, 건물·나무·차 충돌, 움직이는 승강기 바닥.
- **피오르빌 한 동**만 들어갈 수 있습니다: 1층 로비 → 승강기(층 선택 1~15층·옥상) → 복도/옥상.
  층수(15층)는 OSM + K-apt 대조값이지만 **내부 구조(복도식, 로비, 승강기)는 상상으로 만든 것**이며 실제 건물 내부가 아닙니다.
- 건물 외관: 창문 격자, 아파트 베란다(가까이 가면 입체 생성), 옥상 물탱크·승강기 기계실, 1층 상가 간판(간판 이름은 임의), 학교/상가/주택 별도 질감.
- 멀리 보이는 산은 분위기용 장식이며 실제 지형이 아닙니다. 가로등·나무 위치는 OSM 기반이지만 11월 단풍색은 임의 배색입니다.
- 알려진 한계: 길 턱(연석)은 아직 없음, 보행자는 도로 횡단 시 차를 살피지 않음, 실제 폰 성능은 미검증.
